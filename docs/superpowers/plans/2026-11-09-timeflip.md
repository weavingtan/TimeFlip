# TimeFlip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个无 Dock 图标的 macOS 菜单栏番茄钟，并带有可定制、可拖拽、可贴桌面或置顶的翻转时钟挂件。

**Architecture:** `Sources/TimeFlipEngine` 是纯 Foundation 状态机与设置模型（不 import SwiftUI/AppKit），`Sources/TimeFlip` 是 AppKit/SwiftUI 应用层（NSStatusItem + borderless NSWindow + SwiftUI 视图）。不用 SwiftPM/Xcode：`swiftc` 直接编译，`scripts/build-app.sh` 组装 `.app`，`scripts/test.sh` 编译并运行自写断言测试。

**Tech Stack:** Swift 6.1、SwiftUI、AppKit、Carbon HotKey、UserNotifications、SMAppService；macOS 15.6 开发 / 14.0 最低支持。

**Spec:** `docs/superpowers/specs/2026-11-09-timeflip-design.md`

**状态：** 10 个任务全部实现并通过 `scripts/smoke.sh`（2026-11-09）。

```swift
public struct Durations: Codable, Equatable, Sendable {
    public var focusMinutes: Int, shortBreakMinutes: Int, longBreakMinutes: Int, sessionsPerLongBreak: Int
    public init(focusMinutes: Int = 25, shortBreakMinutes: Int = 5, longBreakMinutes: Int = 20, sessionsPerLongBreak: Int = 4)
    public static let standard: Durations
    public func minutes(for phase: TimerPhase) -> Int
    public var isValid: Bool   // 1...180 分钟，(2...8) 轮
}

public struct PhaseTransition: Equatable, Sendable {
    public enum Reason: String, Sendable { case completed, skipped }
    public let from: TimerPhase, to: TimerPhase?, reason: Reason
}

public struct TimerSnapshot: Equatable, Sendable {
    public var phase: TimerPhase, isRunning: Bool, isPaused: Bool, isFinished: Bool
    public var remaining: TimeInterval, total: TimeInterval
    public var completedFocusSessions: Int
    public var nextPhase: TimerPhase?
    public var progress: Double
    public var isCustom: Bool
}

public final class TimerEngine {
    public private(set) var snapshot: TimerSnapshot
    public var onChange: ((TimerSnapshot) -> Void)?
    public var onPhaseTransition: ((PhaseTransition) -> Void)?
    public var autoStartNext: Bool
    public init(durations: Durations = .standard, autoStartNext: Bool = false, now: @escaping () -> Date = Date.init)
    public func start(); public func pause(); public func resume(); public func skip(); public func reset()
    public func startCustom(minutes: Int); public func tick(); public func updateDurations(_ d: Durations)
}
```

### Task 2: 状态机全部转换

**Files:** Modify `Sources/TimeFlipEngine/TimerEngine.swift`, `Tests/EngineTests/main.swift`

- [ ] **Step 1: 追加失败用例**（每条一个 `testXxx()` 函数，runner 依次执行）：
  1. `focus → shortBreak`：`clock += 1500; tick()` 后 `phase == .idle`、`isFinished == true`、`nextPhase == .shortBreak`、`completedFocusSessions == 1`、只有一个 `.completed` 事件。
  2. 第 N 轮长休：`sessionsPerLongBreak = 2`，完成 focus→shortBreak→focus 后第二次 focus 完成 → `nextPhase == .longBreak`。
  3. `autoStartNext = true`：完成后直接进入短休，`snapshot.phase == .shortBreak`、`isRunning == true`、事件 `to == .shortBreak`。
  4. `start()` 从 finished idle 启动 → `phase == .shortBreak`。
  5. 暂停：`start(); clock += 60; pause()` → `isPaused`，`clock += 7200; resume(); tick()` → 仍是 focus 且 `remaining` 在 1439...1440。
  6. 睡眠补时：`start(); clock += 7200; tick(); tick()` → 事件只发一次。
  7. `skip()` 在 focus 中 → 不增加 `completedFocusSessions`、事件 `reason == .skipped`、`nextPhase == .shortBreak`。
  8. `reset()` → idle、`completedFocusSessions == 0`、`remaining == 1500`、`nextPhase == nil`。
  9. `startCustom(minutes: 3)` → `total == 180`、`isCustom == true`；完成 → `nextPhase == .focus`、`completedFocusSessions == 0`。
  10. 非法自定义（0、181）被忽略。
- [ ] **Step 2: 跑测试确认失败**（列出的 `nextPhase`、`isFinished` 相关断言应报错）。
- [ ] **Step 3: 实现转换**：
  - `finish(reason:)`：focus 且 completed → `completedFocusSessions += 1`；`next` 规则 = focus → (completed 且 `completedFocusSessions % sessionsPerLongBreak == 0`) ? longBreak : shortBreak；break → focus。skip 时 focus 的 next 恒为 shortBreak。
  - `autoStartNext` 为真 → `begin(next)` 并带 `to = next` 事件；为假 → idle + `isFinished = true` + `pendingNext = next` + `remaining = 下一阶段时长`，事件 `to = nil`。
  - `begin(phase, overrideMinutes:)` 设 `deadline = now + total`，`progress = 0`。
  - `emit()` 里算 `progress = 1 - remaining/total`（夹取 0...1）。
  - 一次 `tick()` 最多推进一个阶段（`finish` 后直接 return）。
- [ ] **Step 4: 跑测试确认通过**（全部用例 + Task 1 两条）。
- [ ] **Step 5: 提交** — `git commit -m "feat(engine): 完整阶段转换、暂停/跳过/重置/自定义"`
